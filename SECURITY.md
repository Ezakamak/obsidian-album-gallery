# Security Policy

## Supported version

Security fixes are applied to the latest published Album Gallery release.

## Reporting a vulnerability

Do not publish authentication tokens, private vault files, personal information, or private Ekatech Study data in a public issue.

Use GitHub's private vulnerability reporting feature when it is available for this repository. When private reporting is unavailable, open a public issue containing only a non-sensitive summary and request a private contact channel before sharing reproduction details.

Please include:

- Affected Album Gallery version
- Obsidian version and platform
- A concise description of the impact
- Reproduction steps that do not expose private data
- Whether the issue involves local vault access or the optional Ekatech Study connection

The maintainer will acknowledge actionable reports and coordinate a fix and disclosure timeline appropriate to the severity.
